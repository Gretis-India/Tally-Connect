How to Enable XML Server in Tally Prime

Follow these 3 steps on your Windows machine running Tally Prime:

Step 1: Open Tally Prime Configuration

Press F1 (Help) -> Settings -> Connectivity.

Step 2: Enable Client / Server

Set TallyPrime acts as to Both or Server.

Step 3: Set Port and Restart

Set Port to 9000 (default) or your chosen port. Enable Accept requests from local / all IP addresses. Save and restart Tally Prime.

Configure Tally Prime Connection

Set the host IP, port, or URL where Tally's XML Server is listening.

💡 Tip: If Tally is running on the same Windows PC as Tally Connect, use http://localhost:9000. If Tally is on another machine on your LAN, use http://[Machine-IP]:9000.
